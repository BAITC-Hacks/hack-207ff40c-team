# Attribution and reuse register
No third-party research code has been incorporated yet.
The research catalog describes public leads, not approval to reuse every repository.

For each incorporated component record:
Paper/repository URL; author; exact version/commit; file/component used; license at that
version; required notices retained; modifications; whether copied/adapted/independently
implemented; date introduced; local smoke-test command/result; role in the demo.

Our own contribution must be stated separately from the research method.
A missing or ambiguous license needs resolution before code reuse. Do not infer a blanket
repository license from a nearby project or from the fact that code is public.
